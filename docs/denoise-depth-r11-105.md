# r11-105 语音降噪强度对照

r11-104 实板射频来话到本机喇叭输出降噪 1309/1309、到网络 1312/1314，网络来话到模拟桥接 82/82，I2S 三项错误计数均为 0。用户反馈开启后降噪听感仍不明显。

r11-105 将所有已开启路径的 SpeexDSP 最大噪声衰减设为 15 dB。各线路沿用已保存的独立开关、16 kHz 和 10 ms 分帧。采集侧提前量为 40 ms，网络来话侧为 30 ms，仍由后台处理并按截止点选用对齐的音频。

## 离线音频对照

在 16 kHz 中文合成语音上分别叠加白噪声、偏高频的嘶声和含低频谐波的模拟风扇噪声，覆盖 +5 dB 与 −2 dB 输入信噪比、直接开口与前置一秒底噪。使用随固件构建的同一份固定点 SpeexDSP 比较。

| 度量 | r11-104（6 dB 上限） | r11-105（15 dB 上限） |
| --- | ---: | ---: |
| 话后稳定底噪 RMS 降幅 | 5.9–6.0 dB | 13.3–13.9 dB |
| 前置噪声 0.45–0.95 秒 RMS 降幅 | 5.2–5.3 dB | 8.1–8.4 dB |
| 整段语音电平额外变化（对 r11-104） | — | 下降 0.03–0.24 dB |

最弱样本的字头和字尾电平比上一版分别额外下降最多 0.83 dB 和 0.61 dB。合成样本的语音电平由输出与干净原声的投影估计，语音期间的噪声和失真另计入残差。实际台机噪声、弱信号可懂度和桥接收听需现场对照。

## 实测

用同一次接收条件和同一组音量、EQ、静噪设置，在网页「音频调校 → 调音台 EQ → 语音降噪」切换对应线路，分别听停顿底噪、弱信号的第一个字和结束前的最后一个字。切换后等下一话段生效。网络桥接在模拟端收听，公网直连和 MQTT 分别记录。

当前候选提供 r11-104 回退用的 OTA 与全量镜像。网页升级使用 OTA 应用镜像。
