# r11-107 定时重启与彻底恢复出厂实测

固件基于 r11-106，配套 APP 1.2.20（32）。网页和 APP 的维护页均可设每周重启。彻底恢复出厂入口在网页和手台 SW1。

## 安装

- 网页 OTA 选择 heimao-app-OTA-r11-107.bin。USB 刷机工具 1.1.5 手动选择 heimao-full-r11-107.bin，按需选择保留配置或全新刷机。
- APP 使用 heimao-android-1.2.20-heimao.apk。原签名安装可覆盖升级，旧版手台仍显示小时制维护设置。
- rollback 目录提供原 r11-106 OTA 和 full。回退固件会读取它自己支持的配置。彻底恢复已清除的设置需要重新填写或导入事先保存的备份。

## 每周定时重启

1. 让手台连上能访问 NTP 的 Wi-Fi，打开网页「设备与维护」或 APP 设备维护页。先确认「已校时」和最近校时。
2. 选今天，设置几分钟后的时间并保存。页面应显示北京时间下次重启。再试选两天并回读，确认切换页面和刷新后两天都已保存。
3. 到点观察手台离线并重新上线。核对启动标识已改变、最近启动为定时重启、原配置可读。同一分钟应只执行一次。
4. 可用能保持局域网连通的网络策略暂时断开 WAN，验证已校时的手台仍按计划运行。首次上电尚未校时会等待。联网后通常每小时同步，重连时主动校时，超过 24 小时未校准暂停计划。

时间采用 UTC+8，所有勾选的星期使用同一时分。新计划默认关闭，旧小时计划升级后需重新设置。到点会停止当前通联，再重启 ESP32 并重新初始化射频、音频和网络。OTA 或关键文件写入结束后才执行，成功 OTA 产生的重启已经完成这次重启。关机期间错过的计划跳过。自动资源维护继续按连续空闲时间判断。

## 彻底恢复出厂

1. 用可清空的测试手台。先分别保存用于对照的 Wi-Fi、设备名、信道、尾音、降噪与计划等设置。
2. 网页点「彻底恢复出厂设置」并确认。受理后原 Wi-Fi 会断开，擦除期间可能需要数秒。看到「黑猫智能手台-XXXXXX」配网热点后重新配网，核对没有旧信道、尾音、对端、设备名或重启计划，射频重新进入初始设置。
3. 重新填入有辨识度的测试资料。运行中按住 SW1，约 10 秒后松手，重复检查。短按约 3 秒松手打开配网热点。运行中长按后的松手时机有助于避免 BOOT 脚在重启时进入下载模式。
4. 如要验证断电恢复，用空闲测试台，在已受理的恢复擦除期间断电一次并重新上电。比较软件恢复和 USB 选择同版本全新刷机后的首次启动状态。

同版本板载恢复会清除 NVS、文件分区、崩溃转储、未使用的 PHY 数据区与备用 OTA 固件槽。设备继续启动通过校验的当前版本，引导程序和分区表由 USB 全新刷机流程重写。恢复成功后旧配置无法从板上取回。若设备持续快速闪灯且没有出现热点，串口可查看擦除失败原因。重新上电会续做持久化记录中的恢复请求。
