# 快速上手

从零到能通联：刷机 → 配网 → 面板 → APP。

## 你需要

- 一台黑猫智能手台（ESP32-S3-N16R8 + SA818S + ES8311，见 [硬件](hardware.md)）；
- USB **数据线**（不是充电线）；
- Windows 10/11 电脑（刷机）；
- Android 7.0+ 手机（APP，可选）；
- 天线或假负载（发射前必须接）。

## 1. 刷固件

1. 从 [Releases](../../releases) 下载 `黑猫互联-full-r11-83.bin` 和 `黑猫互联刷机工具-<版本>.exe`；
2. 解压工具到可写目录，双击运行；
3. USB 连接手台，等待列表出现 COM 口并勾选；
4. 点击“选择 BIN”，选中 `full.bin`；
5. 首次刷机选“全新刷机”；已有配置要保留时选“保留配置”；
6. 点击“开始刷写”，等待写入与校验完成。

工具会校验镜像类型、分区布局、芯片型号与 Flash 大小。失败时不要反复重试，先看 [刷机排错](flashing.md#常见错误)。

## 2. 配网

1. 首次开机（或清空 Wi-Fi 后）手台会开启开放热点，名称类似 `黑猫智能手台-XXXXXX`；
2. 手机/电脑连接该热点；
3. 浏览器打开 `http://192.168.4.1/`；
4. 选择你的 Wi-Fi、输入密码，保存；
5. 手台重启并加入局域网。

> 热点是开放的，只用于配网；配网完成后会自动关闭。不要在公共场合长期停留在配网模式。

## 3. 打开控制面板

1. 在路由器管理页或手台串口日志中找到手台 IP；
2. 浏览器访问 `http://<手台IP>/`；
3. 需要浏览器麦克风（网页发话）时，改用 `https://<手台IP>/`，接受一次自签证书告警。

面板里可以：

- 设置频率、功率、亚音、静噪、音量；
- 管理 99 个信道；
- 调整音频增益与 6 段 EQ；
- 选择网络模式（局域网 / P2P / MQTT 中继）与桥接；
- 上传自定义尾音、检查状态、OTA 升级。

## 4. 安装 APP

1. 安装 Release 中的 APK；
2. 手机与手台在同一局域网；
3. APP 自动发现或手动输入 IP；
4. 连接后可发话、收听、改参数、上传尾音、升级固件。

网页与 APP 可以同时连接。当前固件**没有控制租约**：写操作由板端串行锁保护，两个入口同时改参数时后到者会收到 `409 device mutation in progress`，稍后重试即可；发话音流按会话隔离。

## 5. 第一次通联

1. 接好天线，确认频率在你有权使用的范围内；
2. 面板选择信道或直接设频率；
3. 按住 PTT 说话，松开发射；
4. 对端（另一台手台 / 网络对端）应能听到，并在松键后听到一次尾音。

> 不要在没有天线、没有执照或不允许的频率上发射。发射功率与频段受当地法规约束。
