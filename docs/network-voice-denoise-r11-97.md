# r11-97 语音降噪实测说明

## 在手台网页设置

打开「音频调校 → 调音台 EQ → 语音降噪」。勾选要处理的出口，点「保存降噪设置」，新设置在下一话段生效。「撤销未保存修改」恢复当前模式及共用项的最近确认值。切换 MIC/SPK、页面、简洁版或详细版时会保留草稿。

| 声音来源 | 本地模拟 | 公网直连及 MQTT 网络中继 |
| --- | --- | --- |
| 手台发话 | 发到本机射频 | 发到本机射频、发到当前网络 |
| 射频来话 | 本机喇叭 | 本机喇叭、转发到当前网络 |
| 网络来话 | — | 本机喇叭、模拟桥接 · 射频发出 |

两项本机设置跨模式共用。四项网络设置按模式分别保存。实际桥接发射时，SA818 调制输入和本机喇叭共用 DAC，使用「射频发出」设置。单独守听使用「本机喇叭」设置。听感以实际射频对端为准。APP、网页的音频入口和 Hub 压缩包透传沿用现有路径。

升级时继承 r11-96 的两项本机设置和两项射频转网络设置，六个新增选项默认关闭。整卡一次提交，成功后进入版本化配置。降回 r11-96 时读取升级前的旧配置。可在「运行详情」查看处理帧、单帧最高耗时和超时计数，分配失败或超过处理时限会走原声旁路。

## 实测顺序

1. **本地模拟** · 单独开启手台发到本机射频、单独开启射频来话到本机喇叭，再两项同开。听本机及射频对端，比较首字、尾字、底噪。
2. **公网直连和 MQTT 各测一遍** · 手台网发分别测「仅网发」和「网络＋本机射频」。独立切换两路降噪，分别在网络对端和射频对端听。再用外部手台测本机收到的射频语音转发到网络。
3. **网络来话的两个出口** · 两种网络模式都测全关、只开喇叭、只开模拟桥接、两项同开。桥接关闭时听本机喇叭，桥接开启时听实际射频对端，记录远端极短按键的首尾字、尾音和释放载波。切换发送者后留意是否带出上一人声音。
4. **设置回读** · 切换两种网络模式核对各自配置。断开再重连网页或重启手台后核对保存值。用手机页面试切 MIC/SPK 和简洁／详细布局，看未保存的勾选是否保留。

附 r11-96 回退 OTA 与完整 BIN。候选目录中的 `heimao-app-OTA-r11-97.bin` 用于网页 OTA，`heimao-full-r11-97.bin` 用于 USB 刷机工具。这一轮桌面环境验证覆盖固件构建、主机音频与桥接时序、浏览器交互及刷机工具离线识别。真实网络通联、DAC 听感、射频载波及 S3 运行时记录由实板验证。
