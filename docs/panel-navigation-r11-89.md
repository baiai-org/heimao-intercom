# 网页面板六页导航（r11-89）

用户确认六页方案后实施。默认进入对讲，桌面左侧菜单，手机底部常用入口与“更多”。

- 对讲：频率、手台/浏览器麦克风选择、发话与守听、手台音量、通联摘要。详细仪表和运行状态按需展开。
- 网络互联：模式、房间、地址、对端/拒绝列表、Hub；STUN 与详细诊断折叠。
- 模拟桥接：当前模式的桥接信道、开关和毫秒接收保护。
- 射频与信道：射频参数和预设信道两个子页。
- 音频调校：增益、尾音、均衡器三个子页。
- 设备与维护：名称、实体按键、网络设置入口、日志、升级、恢复。

导航移动原有控件，保留唯一 ID、事件、文件选择和音频会话。导航与设备通信模式分别控制；
正常切页继续网页收听。切页/切换麦克风先停止本网页发射并等待确认，失败保留当前页面及重试入口。
其他来源的发话不会因浏览页面而被停止。频率、房间、STUN、MQTT 输入保留草稿；保存成功后才清除脏标记。
接收保护和名称继续使用各自原有草稿管理。自动提交的滑块/选项维持原有行为。

验证使用实际 HTML + 本地模拟 HTTP，覆盖六页唯一显示、手机更多入口、模式不因导航改变、草稿跨刷新保留、
频率保存清除草稿、发话停止失败/成功、收听持续、桥接/音频/维护入口及截图。工具为 tools/verify_panel_navigation.cjs，
设置 PLAYWRIGHT_MODULE 指向已安装 Playwright，CHROME_PATH 可指定 Chrome 路径，
PANEL_TEST_OUTPUT 指定截图/记录输出目录。它不联系实板。另覆盖浏览器停止确认不匹配、
重试失败/成功、三种通信模式的桥接显示；停止请求有超时，不能把未匹配的响应当确认。

本轮 APP 源码与 APK 均复用 1.2.18；固件/网页版本 r11-89。真实浏览器麦克风、两台网络通联、USB 与实际发射仍待验收。
本次不把模拟 HTTP 的成功当成设备部署或真实收发验收。构建、离线回归与产物哈希见候选 BUILD-INFO。
