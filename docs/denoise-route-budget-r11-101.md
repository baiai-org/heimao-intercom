# r11-101 降噪复测说明

r11-100 的两次本地模拟 10 秒测试分别处理了 178 帧和 18 帧再旁路，最高耗时 3814 μs。故障点落在连续两帧超过 2500 μs 的规则。

r11-101 在单路降噪时允许每帧最多 4000 μs。同一个音频任务可能同时处理两路时，每路以 2500 μs 为目标，容忍一次孤立慢帧，连续两次超目标会触发旁路。两种情况下，任一帧超过 4000 μs 会触发旁路。本话段降噪切回原声时使用最多 5 ms 渐变。

优先实测单路开启和双路同开。用「运行详情」比较每段话新增帧数和超时次数。实板过程及音频链路覆盖记录见候选的 validation 目录。测试包包含 r11-98 回退固件。
