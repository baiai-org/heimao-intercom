# r11-106 分线路语音降噪挡位

打开网页「音频调校 → 调音台 EQ → 语音降噪」，为对应线路选择挡位，再保存整张卡。运行详情显示已保存挡位、当前或最近话段实际使用的挡位，以及降噪、原声和迟到等计数。

| 挡位 | SpeexDSP 的最大噪声衰减 | 用途 |
| --- | ---: | --- |
| 关闭 | 0 dB | 原声直通 |
| 轻度 | 6 dB | 轻压底噪 |
| 标准 | 15 dB | r11-105 的强度 |
| 强力 | 24 dB | 更深的频谱降噪 |
| 极强 | 36 dB | 最大程度压低底噪，弱话音和尾音可能变轻 |

同一话段采用接通时的挡位，保存后从下一话段起应用。手台发到本机射频、射频来话到本机喇叭为共用设置。公网直连和 MQTT 中继分别保存手台网发、射频转网络、网络进喇叭、网络进模拟桥接射频四项。桥接键控时，送往射频的共享音频采用模拟桥接挡位。

旧版已开启的线路读作「标准」，关闭项读作「关闭」。新挡位保存在独立的 NVS 记录中，回退 r11-105 时按升级前相应的旧版开关记录读取。网页 OTA 使用应用镜像。候选包附 r11-105 的 OTA 与全量回退镜像。

## 降噪与试听

各挡使用固定点 SpeexDSP 1.2.1 的同一套 16 kHz、10 ms 频谱降噪。极强档按开源算法对噪声频段施加更低的增益，保留连续采样；纯底噪素材仍可能有残余。后台异步处理采用采集侧 40 ms、网络来话侧 30 ms 提前量。

同一组中文合成语音分别叠加白噪声、模拟嘶声和模拟风扇噪声，覆盖 +5 dB 与 −2 dB 输入信噪比、直接开口与前置一秒底噪共十二种组合。下表是话后稳定底噪实测 RMS 降幅，相对关闭档。

| 轻度 | 标准 | 强力 | 极强 |
| ---: | ---: | ---: | ---: |
| 5.9–6.0 dB | 13.3–13.9 dB | 18.1–19.9 dB | 21.1–26.0 dB |

极强相较标准多压 7.6–12.1 dB 的稳定底噪。在这组样本里，极强的整段语音电平额外下降最多 0.15 dB，最弱字头额外下降最多 0.62 dB。前置底噪 0.45–0.95 秒的极强档降幅为 9.5–10.2 dB，初始降幅随底噪估计建立而变化。现场噪声分布、模拟电路和信号强度会影响听感。

同一音量、EQ 和静噪下，分别试听「标准、强力、极强」三个话段。检查停顿底噪、短按的第一个字与弱信号尾字。模拟桥接在模拟端收听，公网直连和 MQTT 分开记。运行详情可用于核对每次实际生效的挡位及原声回退。
