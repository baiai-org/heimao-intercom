# r11-104 按输入批次调整降噪提前量

r11-103 在 16 ms 采集路径用 30 ms 提前量时，部分 10 ms 降噪帧的任务提交和取用落在同一采集批次。后台来不及在前台取用前交出这帧。加上连续三帧就绪才恢复的规则，离线复现为每 8 帧约 2 帧实际使用降噪，与射频来话双出口约 24.9% 覆盖率吻合。

| 输入 | PCM 提前量 | 出口 |
| --- | --- | --- |
| 本机 16 ms 采集 | 40 ms | 手台发话到射频或网络，射频来话到喇叭或网络 |
| 公网直连、MQTT 的 20 ms 来话 | 30 ms | 本机喇叭和模拟桥接射频 |

按路径安排后台工作后，前台仍按时选用已对齐的降噪或原声 PCM。30 ms 与 40 ms 是适配器的样本提前量，实际端到端延迟由设备测量。

离线回归让后台只在前台完成整块采集后运行。两种模式以 848 帧射频样本同时送喇叭和网络，喇叭 848/848 使用降噪，网络转发 847/848，最后一帧按截止点送原声。两种网络模式的两个来话出口各用 914 帧测试，均为 914/914 使用降噪。

## 真机复测

1. 自行上传 `heimao-app-OTA-r11-104.bin`。让射频来话同时送本机喇叭和网络，两个降噪同时开启。每种模式测一段约 30 秒语音和几次短按。
2. 在「运行详情」对比两条路径的本话段输入、降噪输出、原声和恢复次数。听首尾字和是否还有周期性起伏，同时检查 I2S 欠载。
3. 分别回归公网直连和 MQTT 的网络来话到模拟桥接，听对端首尾音并核对载波释放。手台发话的本机射频和网发也各测一次。

候选附 r11-103 回退 OTA 和完整 BIN。设备操作及一切实际发射由用户执行。
