# r11-96 调音台收发降噪测试

基于 r11-95。简洁版打开「音频调校 → 均衡器」，详细版打开调音台大卡片。在六段推子下方，使用原来的「发射（MIC）」和「接收（SPK）」标签切换降噪设置。

| 模式和面板 | 设置 |
| --- | --- |
| 本地模拟，发射（MIC） | 手台麦克风 → 射频 |
| 本地模拟，接收（SPK） | 射频接收 → 本机喇叭 |
| 公网直连 / MQTT，接收（SPK） | 本机喇叭和当前模式的射频接收 → 网络转发分别控制 |
| 公网直连 / MQTT，发射（MIC） | 启用本机射频发射时，显示手台麦克风 → 射频 |

本地两个开关默认关闭，r11-95 的两个网络转发设置延续。当前话段继续使用话段开始时的值。开关与 EQ 归零/预设分别保存。状态读取独立进行，轮询期间按钮保持可点击；保存提示出现在操作行。保存失败由设备配置回读确认。旧 GET 或设备身份不匹配的响应无法盖过当前结果。

算法仍用 SpeexDSP 1.2.1 定点 16 kHz、10 ms 帧、轻度 −6 dB 参数。手台发射、喇叭和桥接用各自的算法历史。手台麦克风同时走网络和射频时，网络先走原音频链，射频分支在 MIC EQ 前降噪。喇叭降噪在分出手机/网页和网络音频后、喇叭音量前运行。

本机 DAC 路径设置 20 ms PCM 预填。正常结束按原采样节奏排完有效语音，发射沿用一次板载尾音；写入 DAC 的尾部 PCM 还需经过驱动缓冲，实际收尾时间请记录。遇到保护、换源或失去 PTT 所有权时取消未提交的缓存。分配失败用原声；单帧计算超过 2.5 ms 时后续用原声，已排队样本按原顺序提交。实际射频效果、板上 DSP 耗时和运行余栈需要实测。

## 实测顺序

1. 用正常接收的单台板通过网页上传 r11-96 OTA 应用镜像。若升级前是 r11-95，先核对原公网直连和 MQTT 的设置。
2. 本地模拟分别测全关、只开发射、只开接收、两者都开。发射设置在对端录音比较，接收设置从本机喇叭比较。使用相同音量、语句和接收条件，记录弱信号、首尾字、短按尾音次数和松键后载波结束时间。
3. 分别测试公网直连、MQTT 的桥接转发。在开喇叭降噪和转发降噪的组合下，核对每个出口的效果。网发和本机同发时，检查发射降噪只改变射频分支。
4. 记录 EQ 降噪区的实际工作状态、处理帧、最高耗时和超时次数。慢网络下等待数次刷新，确认开关显示稳定。重启后核对两项新配置和此前的网络配置。
5. 如需回退，可使用升级前留存的实际应用镜像，或测试包中与原 r11-95 候选一致的 OTA。走 USB 保留配置模式时选择独立的 full BIN。
