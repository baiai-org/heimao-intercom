# 详细版 / 简洁版切换（r11-90）

状态栏最前面、Wi-Fi 状态之前增加 150 × 48 px 起的切换按钮，16 px 文字；手机独立一行。
默认简洁版（r11-89 六页），详细版恢复原集中排列和手机模块筛选。按钮显示要切换到的版本。
按当前设备 device_id 保存到本浏览器 localStorage；新设备默认简洁，存储不可用时仍可切换。

切换只移动同一套节点；保留控件/事件、草稿、文件选择、实时列表及收听会话，不刷新页面。
只恢复被布局修改的结构关系，不恢复动态列表/状态快照。本网页发射先确认停止，失败保留布局并显示提示/重试。
页面导航与布局分离，回到简洁版保留先前页及子页；手机旧模块筛选不会导致简洁页丢控件。
页头按钮和停止错误提示在两种布局中均可见。自动恢复详细版也遵守停止确认。

APP 复用 1.2.18；候选固件 r11-90，不自动部署设备或推送远端。
验证使用 tools/verify_panel_navigation.cjs 的实际 HTML + Chromium 模拟 HTTP，含原六页回归、反复切换、
输入和文件节点身份、列表/草稿/收听、停止失败与成功、布局记忆和设备隔离、桌面/手机截图。
真实设备音频、USB、射频及浏览器麦克风待用户实测，模拟的状态保留不等于真实音频已验收。
