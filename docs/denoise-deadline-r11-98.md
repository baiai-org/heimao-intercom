# r11-98 降噪抖动复测说明

r11-97 实测反馈是三种模式启用降噪时有轻微抖动，关闭后语音恢复。一次短按后页面显示处理 21 帧、最高耗时 7605 μs、累计超时 2 次。最高耗时超过单帧 2500 μs 预算。累计数据用于确认曾经超时，单次短按是否新增超时需对照按键前后的计数。

r11-98 的 ESP32-S3 构建只对 SpeexDSP 组件使用 `-O2`，以降低处理耗时。已输出降噪声音时，超时帧使用已算出的结果和对齐的原声渐变，最多 80 个样本，即 5 毫秒。短尾帧按有效样本数缩短渐变。尚未送出降噪音频就超时时直接送原声。首个超时后，该话段余下部分沿用原声。处理预算仍为 2500 μs，计数继续累计。

所有 r11-97 的降噪路径继续沿用各自的勾选值。编译优化能否让实板持续跑进预算、不同链路上的实际听感，由实测确认。离线回归覆盖中途超时、短尾帧、定速 DAC 输出、首尾样本和原声旁路。

## 上机复测

1. 用 `heimao-app-OTA-r11-98.bin` 升级一台手台。在「调音台 EQ → 语音降噪 → 运行详情」记录待测路径的帧数、最高耗时和超时计数。
2. 先重现同样的短按，再正常说一段约 10 秒的话。看这一轮超时计数增加了多少，同时听是否还有抖动。网页切换降噪后在下一话段生效。
3. 本地模拟、两种网络模式与模拟桥接至少各测一次。桥接从另一台射频手台听。优先核对抖动、首尾字和尾音。

候选包内附 r11-97 回退 OTA 及完整 BIN。USB 刷机使用 `heimao-full-r11-98.bin`。
