# 黑猫互联 · Heimao Intercom

![黑猫互联](assets/brand/icon-512.png)

## 它是什么

| 部分 | 说明 |
|---|---|
| 手台固件 | ESP32-S3-N16R8（16 MB Flash / 8 MB PSRAM），驱动 SA818S 射频模块、ES8311 音频编解码、前面板按键与 LED |
| 网页面板 | 内嵌在固件里，浏览器打开即可配置频率/信道/音频/网络，支持 HTTPS（浏览器麦克风需要安全上下文） |
| Android APP | Kotlin/Compose，局域网发现、设备会话、PTT 发话、本机试听、参数设置 |
| 刷机工具 | Windows 单文件 EXE，保留配置 / 全新刷机两种模式，多串口并行 |

## 主要功能

- **模拟与网络互联**：支持本地电台、公网 P2P 直连、MQTT 网络中继，可将模拟电台或中继通过网络互通。
- **多设备组网**：公网直连最多保存 **16 个对端**，支持 IPv4／IPv6 和 Hub 中心转发。
- **手机与网页对讲**：Android APP、浏览器支持 PTT 发话和收听，可监听射频接收及网络来话；APP 提供本机录音试听。
- **射频与信道管理**：提供 **99 槽信道库**，支持收发频率、功率、CTCSS／DCS 亚音、静噪和音量设置，提供 **1／2.5／5／12.5 kHz** 频率步长。
- **音频调校与自定义尾音**：支持 **6 段 EQ**、各链路音量调节，以及 WAV／MP3 自定义尾音；尾音由板端统一播放。
- **中继拖尾回传保护**：支持发射后固定时间接收抑制，保护时间 **1～60000 毫秒**；可选择触发来源和屏蔽出口，公网直连与 MQTT 模式分别保存配置。
- **对端连接管理**：公网直连支持删除并持久拒绝对端，由本机明确解除后恢复接入，避免已删除设备反复自动连回。
- **双布局网页面板**：提供简洁版与详细版，按对讲、网络互联、模拟桥接、射频与信道、音频调校、设备与维护六个页面组织，适配电脑和手机。
- **参数写入与状态反馈**：网页、APP 可同时连接，射频参数按字段合并处理；设置操作反馈实际应用与保存结果，亚音设置显示确认或失败状态。
- **配网、升级与诊断**：支持热点配网、mDNS 访问、双分区 OTA 和诊断导出；Windows 工具支持多串口、保留配置或全新刷机，**不内嵌固件，使用独立 full BIN**。

## 使用场景

### 1. 作为本地模拟电台，与普通对讲机通联

装配对应频段的 SA818S 模块后，黑猫可以作为模拟电台使用，通过本机话筒、扬声器和实体 PTT 完成收发。

- **直频通联**：设置相同的收发频率及匹配的亚音，与普通模拟对讲机通信。
- **接入模拟中继**：分别设置接收频率、发射频率和收发亚音，适配中继的上下行参数。
- **保存常用信道**：提供 **99 个信道槽位**，保存频率、功率、CTCSS／DCS 亚音、静噪和音量，减少反复手动设置。
- **细调频率**：支持 **1／2.5／5／12.5 kHz** 设置步长，方便匹配不同的频率安排；频率步长与收发带宽分别设置。
- **实体按键操作**：支持切换信道、调整音量；四个功能键可按使用习惯配置为信道、音量、静噪、模式或桥接等操作。

实际可用频段由所安装的射频模块决定，UHF、VHF 使用同一套固件。

### 2. 用手机或电脑操作黑猫，收听和按键发话

黑猫接入 Wi-Fi 后，可以把设备放在天线、电源或收发条件合适的位置，通过能够访问它的局域网，用 Android APP 或浏览器进行操作。

```text
手机／电脑 ⇄ 局域网 ⇄ 黑猫 ⇄ 普通对讲机或模拟中继
```

- **手机代替本机话筒**：在 APP 中按住 PTT 说话，由黑猫按当前模式发送；浏览器也支持麦克风发话。
- **在手机或电脑上收听**：收听黑猫收到的射频语音，以及公网直连或 MQTT 模式收到的网络语音。
- **网络重发时继续监听**：黑猫将网络来话转为射频发射时，手机或网页仍可收听这份网络来话，便于确认实际收到的内容。
- **远离设备调参数**：查看收发状态，设置频率、信道、亚音、音量、网络连接和尾音，无需每次通过 USB 接入电脑。
- **发话前检查话筒**：APP 提供本机录音试听，用于检查手机录音输入和增益，不触发黑猫射频发射。

APP 与网页通过网络连接黑猫；跨地域语音互联由黑猫之间的网络连接完成。浏览器麦克风需要 HTTPS 安全上下文，同一台黑猫当前提供一个活动的 APP／网页音频收听会话。

### 3. 两地通过网络对讲，选择公网直连或 MQTT 中继

当两地超出直接射频覆盖范围时，可以让两台黑猫通过互联网交换语音。

**公网 P2P 直连**适合希望直接连接对端的场景。支持 IPv4、IPv6 和 STUN 公网地址探测／打洞，按照房间号、密钥和对端地址配置连接。能否建立直连取决于两端网络条件，STUN 不代表所有 NAT 环境都能穿透。

**MQTT 网络中继**适合通过统一服务器汇聚语音的场景。各设备连接到同一个 MQTT Broker，由服务器转发语音；可设置服务器地址、端口及用户名、密码。当前 MQTT 模式以 Broker 作为通联范围。

这两种方式都可以配合本机话筒、APP／网页发话，以及模拟射频桥接使用，按实际部署选择合适的网络路径。

### 4. 多个地点组成一个通联组

多台黑猫需要互通时，可以使用公网直连的 **Hub 中心转发**能力。

例如把 A 设为 Hub，让 B、C、D 等成员分别连接 A，成员语音经 A 转发给其他成员，减少逐台建立互连的配置工作。

- 每台设备最多保存 **16 个公网直连对端**，不含本机。
- Hub 与普通成员的角色分别显示，便于确认组网结构。
- 对端列表区分直接连接和经 Hub 转发的成员，帮助判断语音从哪里到达。
- 显示连接、最近语音及枢纽离线等状态，方便维护多个地点的设备。

推荐使用**单 Hub 星型组网**。16 个对端是连接表容量；当前按轮流发话使用，不提供多人同时混音，也不提供多级 Hub 转发。

### 5. 让两地的普通模拟对讲机通过网络互通

普通模拟对讲机没有网络能力时，可以在两地各放一台黑猫作为射频与网络之间的网关。

```text
A 地普通对讲机 ⇄ 黑猫 A ⇄ 网络 ⇄ 黑猫 B ⇄ B 地普通对讲机
```

A 地对讲机发出的语音，由黑猫 A 接收并送入网络；黑猫 B 收到后，再通过射频发送给 B 地对讲机。反向通联沿相同路径完成。

- **射频转网络**：把本地收到的模拟语音送给远端。
- **网络转射频**：把远端网络语音转发给本地普通对讲机。
- **按信道配置桥接**：选择用于桥接的预设信道，统一应用该信道的收发频率及相关参数。
- **分别控制桥接用途**：公网直连和 MQTT 模式可分别配置对应桥接。
- **手机辅助监听**：在网关一侧连接 APP 或网页，收听网络来话，辅助判断链路是否通畅。

普通对讲机继续使用原有的模拟收发方式，网络连接由两端黑猫承担。

### 6. 连接两座模拟中继，处理拖尾回传和重复触发

在两座模拟中继覆盖范围内分别放置黑猫，可通过网络把两侧通联连接起来。

```text
模拟中继 A ⇄ 黑猫 A ⇄ 网络 ⇄ 黑猫 B ⇄ 模拟中继 B
```

模拟中继在讲话结束后可能继续发出拖尾载波或提示音。黑猫重新接收这段声音并送回网络，可能再次触发另一端发射，因此提供了针对这类场景的保护设置：

- **发射后固定时间接收抑制**：从本机实际射频发射结束开始计时，保护时间可设为 **1～60000 毫秒**。
- **选择触发来源**：可选择由网络桥接发射、APP／网页发射、本机话筒／实体 PTT 发射触发保护。
- **选择屏蔽出口**：保护期间可按需屏蔽射频到网络的回传、APP／网页的射频收听或本机喇叭。
- **两种网络模式分别保存**：公网直连与 MQTT 模式可以使用不同的保护时间和范围。
- **网络话段顺序保护**：处理迟到包、重复包和已经结束的话段，减少旧数据再次影响发射状态。
- **导出事件记录**：出现重复关断声时，可查看 PTT、COS 和网络话段事件，辅助区分射频拖尾与网络重复触发。

保护时间需要结合两侧中继调整。时间过短可能漏过拖尾，过长会影响本地快速接话的开头；两端使用新版固件可获得完整的话段顺序保护。

### 7. 调整不同来源的音量、听感和结束提示

本机话筒、手机话筒、射频接收和网络来话的音量可能不同，黑猫提供分路径调节，便于适配实际设备。

- **分路径增益**：针对相应收发路径调整固定增益，处理“手机发话偏小”“射频转网络偏大”或“网络转射频偏小”等情况。
- **收听与发话 EQ**：提供独立的 **6 段均衡调节**，调整低频厚度、声音主体和清晰度。
- **本机扬声器音量**：按现场收听需求调整，不必用改变整条转发链路音量的方式解决本机听感问题。
- **网络监听独立分流**：网络来话送往手机／网页的监听音频，在射频重发增益处理前分出，方便分别调节射频重发和手机收听。
- **自定义尾音**：可选择内置提示音，或上传 WAV／MP3 作为简短呼号、提示音等结束标记；尾音由板端统一生成和发送。

### 8. 管理多台设备、常用连接和被删除的对端

需要长期维护多台黑猫时，可以给设备设置公共名称，结合 APP 中的设备档案区分不同地点和用途。

网页提供两种布局：

- **简洁版**：按“对讲、网络互联、模拟桥接、射频与信道、音频调校、设备与维护”六页组织，适合日常使用和手机操作。
- **详细版**：集中显示更多设置和运行信息，适合调试与维护。
- 切页和切换布局保留当前设置草稿，正常浏览时可继续收听。

公网直连还提供**删除并持久拒绝**功能。对于已经识别身份的对端，删除后保留本机拒绝决定，重启后继续生效；恢复连接需要在本机解除拒绝或明确执行恢复添加，避免已删除设备反复自动连回。

射频参数设置会反馈应用与保存结果，亚音设置显示正在应用、确认成功或失败，便于判断操作是否完成。

### 9. 首次安装、日常升级和故障维护

- **首次配网**：通过设备配网热点进入配置页，设置 Wi-Fi；联网后可通过 IP 或配置的局域网名称访问。
- **网页 OTA 升级**：上传应用 BIN，通过网络更新固件，适合已正常联网的设备。
- **USB 保留配置升级**：使用 Windows 工具和独立 full BIN，保留 Wi-Fi、信道、参数及自定义尾音等配置。
- **全新刷机**：需要重新初始化设备时，选择全擦模式后重新配网和设置。
- **多串口刷机**：Windows 工具支持多个串口并行操作，便于批量维护。
- **诊断导出**：导出内存、连接错误、射频参数应用状态及近期通联事件，为排查掉线、设置失败和重复发射提供依据。

**刷机工具不内嵌固件。** 工具 EXE 与 full BIN 分别下载，使用时选择目标版本的外部固件文件。

> 这是个人/小团队自组网项目，不是商用对讲机替代品。实际通联距离、音质与稳定性取决于硬件、天线、环境与法规许可。

## 快速开始

### 1. 刷机

1. 下载 `heimao-full-r11-93.bin` 与刷机工具；
2. 用 USB 数据线连接手台，打开工具，勾选出现的 COM 口；
3. 点击“选择 BIN”，选中 `heimao-full-r11-93.bin`（或当前版本）；
4. 选择模式：
   - **保留配置**（默认）：保留 Wi-Fi、信道、参数、自定义尾音；
   - **全新刷机**：擦除整片 Flash，刷完重新配网。
5. 点击开始，等待写入与校验完成。

> 没有 COM 口时：换数据线；按住 BOOT、点按 RST、松开 BOOT 后刷新。ESP32-S3 原生 USB 会枚举为 “USB-Serial/JTAG”。

### 2. 配网

1. 首次开机或长按配网键后，手台开启热点 `黑猫智能手台-XXXXXX`；
2. 手机/电脑连接该热点，打开 `http://192.168.4.1/`；
3. 选择家里的 Wi-Fi 并输入密码，保存；
4. 手台重启并加入局域网，面板地址为 `http://<手台IP>/`（或 `https://<手台IP>/`）。

### 3. 打开面板

- 浏览器访问 `http://<手台IP>/`；需要麦克风时用 `https://` 并接受自签证书告警；
- 面板可配置频率/功率/亚音/静噪、信道、音频增益、EQ、网络模式、尾音、OTA。

### 4. 安装 APP

安装 Release 中的 APK。APP 与网页共用板端发话状态；一方发话时，另一方等待结束。
